Technical Terminology

HTML
HyperText Markup Language used to structure content on web pages.
Frontend
The part of an application that users see and interact with in a browser.
Backend
The server-side part of an application responsible for processing and business logic.
Database
An organized collection of data that can be stored, managed and retrieved.
API
An Application Programming Interface that allows software systems to communicate.
SQL
Structured Query Language used to manage and query relational databases.
